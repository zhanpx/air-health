# Air Health 脱敏教学源码快照

与《Fitbit Air 与 Google Health API：私有健康数据网站部署教程》配套。
这是现有工作区实现的脱敏快照，不是经独立安全审计的生产发行版。
不包含个人账号、Google 配置、令牌、Codex 登录缓存、健康数据库、原始记录、GPS、备份、截图或日志。
此快照按白名单导出，分享时请复核仓库可见性和文件清单。转发或公开发布代码前，请由代码权利人确认授权和第三方许可；本文件不替权利人指定开源许可证。

## 学习顺序

1. 阅读 PDF，准备 Linux、Python 3、systemd 和 SSH。
2. 上传压缩包、解压，在源码目录执行 `sudo bash install-base.sh`。
3. 通过 SSH 端口转发访问 localhost:8765，配置自己的 OAuth Web Client。
4. 验证本人的数据可正常同步后，再考虑登录网关、HTTPS 隧道、AI、MCP 与定时任务。

安装脚本仅接受新安装，不覆盖已存在的 `/opt/air-health/app.py`。默认不安装 cloudflared、不安装 Codex、不启用公网、不启用任何定时器。代码全部使用 Python 标准库；AI 和公网访问需要另外安装官方 CLI。

## 本包与原工作区的差异

- 白名单复制 Python、静态页面和 systemd 单元；主服务单元取自同一项目的初始部署版本。
- 私人服务器别名替换为 `health-server`，调整一处初始配置说明。
- 新增只用于教程的新安装脚本、交互式网关凭据生成器。
- 不包含任何运行时配置。首次运行将新建自己的数据目录。
- `SHA256SUMS.json` 给出本包各文件的哈希，不构成代码签名。

## 已知限制，部署前务必阅读

- 仅面向单用户：一份 Google 令牌和一份数据库；不是多租户系统。
- 原始归档可能跳过已有的历史日期，晚到数据需要针对性重新回填。API 数据类型、过滤字段与设备支持请核对最新官方文档。
- OAuth state 是带 10 分钟有效期的单个服务端状态；并行发起授权会互相覆盖。
- 同步锁是进程内锁，网页后台任务和 systemd 独立进程并不能共享；正式运行需统一队列或跨进程锁。
- 网关为个人实验实现：单密码 SHA-256 摘要，不等同完整身份平台；建议长随机密码、额外身份验证和访问审计。
- AI broker 的模型白名单和网页菜单是快照版本，不能保证其他账号可用。按实际服务可用模型同时核对后端和前端。
- AI broker 调用 `/usr/local/libexec/air-health-codex`，须安装完整官方 CLI 并建立匹配入口。先检查 `codex exec --help` 对参数的支持。
- AI 运行在独立系统用户下；提示词和 read-only 沙箱本身并不等价于完全无工具或无网络。
- 本地图片在正常 finally 路径清理；崩溃残留与上游数据保留需另行管理。
- MCP 是只读工具接口参考实现；数据库只读并不等于操作系统隔离或身份验证。
- 自动周报 CLI 以昨天为结束日，正常每周一运行得到上周一至周日。其他日期手动运行得到截至昨天的滚动 7 天。
- 周报的一些规则为启发式，空值求和、时间范围覆盖和运动条数上限需要生产化改进；不能用作诊断。
- 自带 gzip 备份含健康与路线数据，虽不含 OAuth JSON，却并非匿名或加密备份。
